## Historical backfill (illustrative)
HM Land Registry's complete file is 5.15 GB (HEAD request, Last-Modified Mon, 28 Sep 2026 05:12:22 GMT). At this release's 174 bytes per CSV row that is about 31.7 million rows, and at 18.7 bytes per Parquet row about 0.55 GB of Parquet. Both ratios are scaled linearly from one monthly file, so treat them as rough.

- Storing the raw file plus its Parquet: about $0.1367 a month.
- 500 queries a month that each scanned all history: about $1.34. Partitioning by year and selecting few columns would cut this a lot.
- The handler reads a whole file into memory, and Lambda allows at most 10 GB of memory and 15 minutes, so the 5.15 GB complete file is far too big for one run. A backfill should load the yearly files instead (see docs/DEPLOY.md).
